电力常用术语通俗对照表

一张解码表：听到行话时能对上号、知道归哪一类、够接话提问即可，不要求记定义、不要求会算。按「量 / 装置 / 工况 / 保护 / EMC 试验」分组查；大白话只建第一印象、故意不严谨，精确定义与结果判断不在本表范围。

一、量与单位

术语（别名 / 英文） 大白话 在这类系统里对应什么 容易听错 / 混淆
电压 U（电位差） 推着电流走的「压力」，两点之间的电势差 采集通道里的一路瞬时值 要问是相电压还是线电压、瞬时值还是有效值
交流 AC / 直流 DC 方向来回变、周期性过零的电 / 方向不变的电 通道类型、母线与输出侧的区分 AC 说的是方向变不变，不是「有没有电压」；工频只是 AC 的一种，变频输出也是 AC
电流 I 电荷流动的快慢，像水流大小 另一路采集瞬时值 方向 / 极性约定：正值往哪边流
瞬时值 某一刻的实际数值 波形上的一个采样点 和有效值不是一回事
有效值 RMS 等效发热能力的那个「直流等值」，正弦波 = 峰值 / √2 报表、铭牌额定值 非正弦波不能随手套 √2
幅值 / 峰值 / 峰峰值 Vpp 波形离零点最远的距离 / 最高点到最低点的跨度 波形给定、量程与绝缘校核、限幅判断 幅值 ≠ 有效值；峰峰值 = 2 倍峰值只对对称波形成立
有功 P（W） 真正被消耗或转换掉的平均功率 功率报表 口语说「功率」时常指它，也可能指视在功率
瞬时功率 p(t) 某一刻的 u×i，随时间起伏（含两倍频） 波形级功率、象限切换瞬间 与有功 P 差一个「周期平均」，切换过程里两者能差很远
无功 Q（var） 在磁场 / 电场间来回借还、一周期净额为零的部分 感性 / 容性负载的电流与容量 不是损耗、不是浪费
视在功率 S（VA） √(P²+Q²)，设备容量按它选 功放、变压器的额定容量 单位 VA，不是 W
功率因数 cosφ P 占 S 的比例，越接近 1 越「实在」 效率与容量核算 滞后 / 超前还要看是感性还是容性
相位 / 相角 正弦波走到一圈里的哪个位置 u、i 之间的夹角 φ 单位度或弧度
相量 phasor 把幅值和相位写成一个复数，方便算稳态交流 稳态计算、同步相量数据 只适用单一频率的正弦稳态，瞬态波形不能用
频率 f / 工频 每秒重复多少次；国内工频 50 Hz 波形周期、采样率设定 变频工况下不是常数
谐波 / THD 波形里混进来的工频整数倍成分；THD 是畸变率 波形质量、滤波器设计 非整数倍的叫间谐波
基波 / 谐波次数 波形里那个工频主成分 / 第几次倍频（2 次、3 次…） 谐波分析与 THD 的基准 基波不是直流分量；非整数倍的叫间谐波
三相 / 相序 三根相差 120° 的交流；ABC 的先后顺序叫相序 多通道采集与对齐 相序接反，功率符号和电机转向都反
线电压 / 相电压 两根相线之间 / 相线对中性点（380 V / 220 V） 接线方式与量程 两者差 √3 倍
中性点 / 零线 / 地线 三相的公共参考点 / 引出的导线 / 接大地 参考电位与安全 零线和地线不是一回事
标幺值 pu 实际值 ÷ 基准值，变成无量纲的相对值 不同电压等级放一起比较 不是新单位，必须问基准值取多少
序分量（正 / 负 / 零序） 把不对称三相拆成三套对称分量 不对称故障分析 是数学分解，不是三根实际导线
直流偏置 / 零偏 offset 整个波形被抬高一块 / 采集通道零点不准带来的固定偏差 采集标定、积分漂移、有效值计算 传感器零漂和真实存在的直流分量是两回事
量程 / 分辨率 / 精度 能测的最大范围 / 最小能分辨的台阶 / 离真值多近 ADC 位数、采集通道配置、点表换算 16 位说的是分辨率，不等于 16 位精度；量程选大了小信号看不清

二、装置与部件

术语（别名 / 英文） 大白话 在这类系统里对应什么 容易听错 / 混淆
四象限功放 电压电流都能双向、既能送能量也能吃回能量的功率放大装置 功率仿真与真实装置之间的接口设备 和「信号放大器」完全不是一回事
变流器 converter 电能形式 / 参数变换装置的统称 功率链路的主环节 下面分整流、逆变、斩波
整流 / 逆变 / 斩波 AC→DC / DC→AC / DC→DC，三个方向的变换 前端与输出级 现场常简称「逆变」，要听清方向
PWM（脉宽调制） 用开关的占空比「拼」出想要的波形 给定波形到实际电压之间的环节 有开关频率、有死区，不是理想波形
IGBT / MOSFET / SiC 高速大功率电子开关 决定开关频率、损耗、死区 不是线性放大器，只有开和关
直流母线 DC bus 变流器中间那段直流储能环节 母线电压相当于能量往来的「压力表」 回馈时它会抬升，不是恒定的
直流母线电压 Udc（Vbus / Vdc） 母线两端的电压，原理图上常写成 Udc 变流器中间环节的能量「压力表」 与「直流母线」是同一个东西的量与符号；回馈时会抬升，不是恒定值
制动电阻 / 回馈单元 能量送不回电网就变热耗掉 / 能逆变送回电网的前端 决定四象限能不能真正闭环 有没有回馈能力，直接决定模型该怎么建
变压器 靠磁耦合改电压，顺带做电气隔离 电网侧与装置侧之间 只能传交流，不能传直流
互感器 CT / PT（TA / TV） 把高电压、大电流按比例变成可测的小信号 采集前端 二次侧不能开路 / 短路，有变比和相位误差
电抗器 / 滤波器 挡住高频、把波形抹平滑的电感电容组合 输出滤波与抗干扰 会带来相移和延迟
磁环 / 磁珠 / 共模电感（现场常说「加磁环」） 套在电缆上的一圈磁性材料，专门挡高频共模干扰 采集线、编码器线、网线的抗干扰措施 通常只对高频噪声有效；低频地环路、工频串扰加了也没用，得改布线与接地
屏蔽线 / 双绞线 / 单点接地 金属层包住信号线 / 两根绞在一起 / 只在一处接参考地 弱信号采集的抗干扰与地环路处理 接地不等于随便接大地；多点接地反而引入环流，比不接更糟
隔离 / 光耦 / 隔离放大器 强弱电之间只传信号、不共地的电气隔断 采集与驱动的安全边界、抗共模电压 隔断的是电气连接，隔不断信号延迟；隔离后两侧仍要各自有参考电位
继电保护装置 按定值判断故障、下令跳闸的装置 半实物测试里常见的被测对象 它「发令」，断路器「执行」
断路器 能带负荷开断、能切断短路电流的开关 执行跳闸 和继电器不是同一个东西
负载 / 电源（sink / source） 吸收功率的一方 / 提供功率的一方 四象限里两者角色会互换 说「带载」时要问带的是什么性质
ADC / DAC 模数 / 数模转换 波形进出仿真系统的关口 位数、采样率、延迟都要单独问
HIL / PHIL 硬件在环：模型接真实控制器（信号级）/ 功率硬件在环：模型接真实功率装置（有真实功率交换） 仿真平台形态 PHIL 难得多，稳定性与延迟是核心，不能当 HIL 看
实时仿真器 按固定步长、必须在真实时间内算完一步的平台 整个仿真跑在哪 「快」不等于「实时」，实时指的是不超时

三、工况与运行

术语（别名 / 英文） 大白话 在这类系统里对应什么 容易听错 / 混淆
四象限运行 电压电流双向、功率可正可负地运行 功放能力描述 u-i 平面与 P-Q 平面同名不同物
电动 / 发电 吸收功率 / 反送功率 装置在 u-i 平面落在哪个象限 与「整流 / 逆变」不是同一套分类
回馈 / 再生 能量倒灌回前端 最容易建模失真的工况 要看前端吃不吃得下
感性 / 容性 / 阻性负载 电流滞后 / 超前 / 同相于电压 决定无功大小和电流波形 同一个有功功率，三者电流完全不同
稳态 各量不再随时间变化的状态 大部分报表的取值条件 稳态对得上，不代表切换过程对得上
暂态 / 瞬态 从一个稳态切到另一个稳态的过程 / 短时冲击 四象限切换、投切、故障瞬间 工程里两个词常混用，要确认说的是哪段时间尺度
过零 波形穿过 0 的时刻 死区、切换最易失真处 过零附近最能看出模型是不是理想源
削顶 / 限幅 clipping 超出能力被截平 额定、饱和、保护 结果「看着合理」的常见来源
饱和 加到顶了，再给也不涨 铁芯、放大器、限幅环节 与「限幅」近似，但饱和通常是渐变
死区 dead-time 为防止上下管同时导通，刻意留的一段空白 小信号与过零处畸变 是刻意加的，不是故障
纹波 ripple 直流或输出波形上叠着的一层周期性小起伏，像水面细密的波纹 母线电压、输出波形的「干净程度」 不是谐波：纹波跟着开关频率走，谐波是工频整数倍（见第一组）
纹波电压 / 纹波电流 / 纹波系数 那层起伏在电压、电流上的具体叫法 / 起伏幅值占直流量的比例 滤波电容、电抗器选型与输出质量常拿它当指标 说「纹波多大」要问是峰峰值还是有效值、分母取什么
纹波频率 起伏重复的快慢 一般等于 PWM 开关频率或其倍频 随开关频率变，不是固定 50 Hz；和工频谐波不同源
环流 并联设备之间不经负载、彼此对灌的电流 并机特有，会白白发热甚至炸机 负载电流里看不出来，要单独测
均流 多台并联时各台分担的电流要均衡 并机控制目标 停得有先后，均流立刻失衡
并机 / 主从 多台一起带同一负载 / 一台管给定与同步的控制关系 多机系统架构 主从是控制关系，不是安全关系
同步 / 锁相 PLL 让多台相位对齐 / 跟踪对方相位的环节 并机与并网前提 锁相有捕获时间，不是瞬间完成
孤岛 与主电源断开后还自己带着负载跑的一小块电网 非计划孤岛有触电与设备风险 与「停机」相反，是还在带电跑
空载 / 轻载 / 满载 没接负载 / 带一点 / 带到额定 模型在哪个工作点验证 空载对得上不代表满载对得上，内阻与限幅都在重载才露馅
开环 / 闭环 不看结果直接给 / 拿输出回来修给定 控制方式与稳定性判断 闭环才有稳定性与相位裕度问题，延迟在闭环里会被放大
给定 / 反馈 / 给定值 setpoint 想要多少 / 实际测回多少 / 设定的目标数值 控制器输入输出、点表里的下行量 给定只是软件里的一个数，不等于装置上已经达到的值

四、保护与故障

术语（别名 / 英文） 大白话 在这类系统里对应什么 容易听错 / 混淆
过流 / 过压 / 欠压 / 过温 四类越限判据 最适合放进硬件的硬判据 阈值、持续时间、是否锁存要分别问
过载 overload 超过额定但通路正常、电流没失控 热积累型，通常允许短时 与短路不同：短路电流只受线路阻抗限制，必须瞬时切断
告警 / 预警 还没到停机程度，先报出来 保护的分级：告警 → 降额 → 跳闸 告警不等于故障，也不该直接触发联锁停机
误动 / 拒动 不该动却动了 / 该动没动 保护装置的两类失效 与「定值整定错」不是一回事，多出在采样、逻辑或回路
短路 不该连的两点连上了，电流只受线路阻抗限制 μs～ms 级的危险 与「过载」不同，过载是超额定但通路正常
桥臂直通 shoot-through 上下两个开关管同时导通，直流母线被直接短接 变流器最严重的故障之一 靠死区防，但死区又是波形失真来源
接地故障 对地绝缘破了 漏电保护、绝缘监测 与「零线断开」表现不同
跳闸 trip 断开输出 / 跳开断路器 保护的执行动作 「谁跳的」和「为什么跳」要分开问
保护定值 判据的阈值（多少安、多少伏、多少毫秒） 领域方给的整定参数 谁定的、按什么工况定的，是关键追问
动作时间 从越限到真正断开花了多久 与状态上报周期对比，决定该归哪一侧 上报周期是秒 / 毫秒级，动作时间是微秒级
故障录波 / 录波 故障前后一段时间的高速波形记录 事故反演最值钱的材料 与「状态上报」不同：一个是高频细节，一个是低频快照
联锁 / 急停 任一条件不满足就停 / 人工触发的停机 安全回路 急停是人工动作，联锁是自动判据
fail-safe（失效导向安全） 「授权消失就停」，而不是靠发一条停止指令 安全架构的方向性判据 与 fail-dangerous 正好相反
使能 / 心跳 持续授权才允许跑 / 周期性续签的存活信号 允许运行条件 心跳断了必须默认停
故障锁存 / 人工复位 故障标志一直举着，直到人确认才清 防止瞬态故障自动消失被漏掉 复位指令是非安全动作，可以走软件
SOE 事件顺序记录 带高精度时标的动作顺序表 多机事故反演靠它对时间线 时标精度不够就失去意义
四遥（遥测 / 遥信 / 遥控 / 遥调） 模拟量 / 开关状态 / 下行命令 / 参数调整 点表分类常按这四类 四类混在一张表里最容易对错

五、EMC 与安规试验

术语（别名 / 英文） 大白话 在这类系统里对应什么 容易听错 / 混淆
额定容量 / 铭牌功率（60 kW） 设备铭牌上标的最大输出能力 描述设备大小的参数 是设备能力，不是这次试验施加的能量；kW 是功率，不等于电压或电流
输出端口 / 端口 port 设备上接线出去的那个接口 试验里干扰打进来的位置（施加点） 常规浪涌多测电源输入口；这里测输出口，要单独确认试验时端口是否带电、接不接真实装置
施加 / 注入 injection 人为把干扰信号打进端口 EMC 试验的动作 不是设备正常运行产生的，是外部加进来的
浪涌 surge（雷击浪涌） 一个微秒级的瞬态高压大电流脉冲，模拟雷击感应或电网大开关操作 抗扰度试验项目之一 不是稳态耐压、不是绝缘试验；持续时间极短，考验的是防护器件与泄放路径能不能把这一下能量吃掉
组合波 1.2/50 μs · 8/20 μs 浪涌发生器输出的标准波形：前者是开路电压波，后者是短路电流波 试验波形参数 两个数字分别描述电压波和电流波，不是同一根波的两个参数；μs 级，和工频毫秒级不是一个时间尺度
A+ / A−（端子标识） 某个输出端子或通道的编号 试验施加点的具体端子 属于设备自定义命名，含义必须查端子定义或丝印图，不能按常识推断：可能是相线、差分正端，也可能是直流正极
对 / 线-地 · 线-线 干扰加在哪两点之间 决定试验回路与源阻抗 A+ 对 PE 是线-地（共模），A+ 对 A− 是线-线（差模），两者泄放路径与考核点都不同
共模 / 差模干扰（common / differential mode） 两根线一起相对地抖动 / 两根线之间相对抖动 干扰的两种耦合方式 共模能量走对地泄放（防护器件 → PE → 大地），差模走端子之间的钳位；整改手段不同
PE（Protective Earth，保护地） 黄绿线、接机壳与接地排的安全地 浪涌对地泄放的终点 不是零线 N、不是信号地 GND / AGND（见第一组）；接混会出安全问题
N / GND / AGND（零线 / 信号地 / 模拟地） 工作电流回路 / 电路参考电位 / 模拟部分参考地 与 PE 并列的几类「地」 名字都带「地」，但只有 PE 是安全保护用；试验描述里的「对 PE」不能替换成「对 GND」
1 kV / 试验等级 外加干扰的开路电压峰值，按 0.5 / 1 / 2 / 4 kV 分档 浪涌严酷度档位 不是设备输出电压，也不是耐压值；等级编号在不同标准版本、产品规范里略有出入，以试验依据文件为准
GB/T 17626.5 / IEC 61000-4-5 浪涌抗扰度试验依据的标准号 试验方法与判据的来源 国内标准等同采用 IEC 标准；引用时要带年份 / 版本，不同版本波形与等级细节有差异
耦合 / 去耦网络 CDN 把浪涌耦合进被测端口、同时挡住它窜回电网或辅助设备的接口网络 试验接线里的标准附件 不是被测设备的一部分；去耦做不好会连带影响同网其他设备
源阻抗 2 Ω / 12 Ω 发生器内部的等效输出电阻 决定脉冲电流大小 线-线常用 2 Ω、线-地常用 12 Ω（不同标准 / 版本表述略有差异）；同一个 1 kV，两种接法打进去的能量不同
极性 / 相位同步 正、负各打几次；交流端口按 0° / 90° / 180° / 270° 对准波形相位打 试验施加方式 直流输出端口没有相位同步这一说；次数与间隔按标准，不是随便打一下
抗扰度 immunity / EMC（电磁兼容） 设备扛住外来干扰、不坏不误动的能力 / 电磁兼容总称 型式试验类别 EMC 包含「抗扰度（挨打）」和「发射（不扰人）」两半，说「做 EMC」要问清是哪一半
EFT 脉冲群 / ESD 静电 / 电压暂降 另外几类常见抗扰度项目：快速脉冲串 / 静电放电 / 供电短时掉压 与浪涌并列的试验项目 各自波形、耦合方式、考核点不同，不能互相替代；口语里常被笼统说成「打干扰」
性能判据 A / B / C / D 试验后设备表现的合格分级：A 无降级、B 暂时降级可自恢复、C 需人工干预、D 损坏不可恢复 判定试验通过与否的依据 是「功能表现」分级，不是「有没有被打坏」；判据取哪一级要事先约定
瞬态异常 / 误告警 浪涌瞬间状态跳变、通信瞬断、采集尖峰、误报 试验期间上位机看到的现象 是外部注入的瞬态，不是软件缺陷、不是真实工况数据；锁存成永久故障会把 B 级拖成 C 级
钳位 clamping 把电压硬压在某个上限，多余能量引走 防护器件动作方式 钳位后仍有残压，不是把干扰完全消掉；后级还得扛得住这个残压
压敏电阻 MOV / TVS / 气体放电管 GDT 几种常用的瞬态防护器件，超过阈值瞬间导通泄放 端口防护电路 响应速度、通流能力、寿命各不同；老化或动作后可能失效，需要定期核查
泄放路径 / 接地参考平面 干扰能量从端口经防护器件、PE 回到大地的那条通路 / 试验用的基准接地平面 决定浪涌能量往哪走 路径阻抗稍高，1 kV 就会在别处找路，表现为莫名复位或通信中断
爬电距离 / 电气间隙 沿绝缘表面的距离 / 空气中两导体直线距离 绝缘与安规设计参数 线-地浪涌主要考验这一段；与「绝缘耐压」不是同一件事
绝缘耐压 / 耐压试验（hipot / 介电强度） 加一个持续的高压，看绝缘会不会击穿 安规试验 是稳态 / 缓升高压，考核绝缘；浪涌是微秒级脉冲，考核防护与泄放，两类试验不能互相替代
Y 电容 / X 电容 跨接在线与地之间 / 线与线之间的安规电容 滤波与共模泄放 Y 电容正是共模干扰对地泄放的通道，同时会带来漏电流；整改时不能随意加大
型式试验 / 例行试验 设计定型时做的全套考核 / 每台出厂做的常规检验 试验性质 浪涌属于型式试验，不会每台都打；别把型式试验结论当成每台设备的实测记录
