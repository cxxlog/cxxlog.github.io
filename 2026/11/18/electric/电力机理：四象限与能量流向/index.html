电力机理：四象限与能量流向

一、四象限到底是什么

把电压 u 放横轴、电流 i 放纵轴，两者各可正可负，于是平面被切成四块。真正决定能量去向的是 p = u × i：

象限 u i p = u·i 装置在做什么 常见工况
I + + + 向外送功率 正向加载、电动
II + − − 吸收反送回来的功率 发电、回馈、卸载
III − − + 极性反转，仍在送功率 反向加载
IV − + − 极性反转，仍在吸收 / 回馈 反向发电

关键一句：「四象限」说的不是四种工况，而是「电压和电流都能双向、功率可正可负」这个能力。只能单向输出电压电流、只能往外送功率的电源，是一象限设备。I / III 象限 p 为正，装置是源；II / IV 象限 p 为负，装置是负载（在吃回能量）。

类比：带能量回收的车 — 踩油门相当于向外送功率（I / III），踩刹车并回充相当于能量倒灌回来（II / IV）。

类比在哪失效：电里没有惯性质量，回馈是瞬时电磁过程，不存在「车速慢慢降」；而且能不能真的把能量送回电网，取决于前端变流器有没有回馈能力——没有的话只能靠制动电阻把能量变成热耗掉。这一条现场极常见，也最容易被仿真漏掉。

别误会（一个真实的歧义）：「四象限」在两套语境里指的不是同一个平面。功放 / 电机拖动侧多指 u-i 平面（电压电流方向）；电网 / 变流器侧常指 P-Q 平面（有功无功方向，对应整流 / 逆变、容性 / 感性）。两者都叫四象限，讨论前先确认对方说哪个。

二、为什么「功率放大器」不是普通放大器

普通信号放大器放大的是电压波形，负载几乎不取功率；功率放大器接的是真实装置（保护装置、继电器、逆变器、电机模拟器……），它必须：

  • 既能当电压 / 电流源向外送能量（source）
  • 也能当负载把装置反送回来的能量吃掉（sink）

软件侧给定的是波形，装置会响应、会反送能量，功放必须「吃得下」。这就是四象限能力的由来，也是仿真里最容易出问题的接口：

环节 软件侧看到 真实装置侧
给定 一段电压 / 电流波形 经 D/A、PWM、功放、滤波才到装置，带延迟与带宽限制
响应 采集回来的波形 装置可能反送能量、可能非线性、可能触发保护
边界 波形数值 电压 / 电流 / 功率额定、母线电压、散热、保护阈值

别误会：把功放当理想电压源建模，在装置纯吸收时也许对得上；一旦装置进入回馈工况，理想源会「无条件吃下」任意反送能量，仿真得到一条完美波形，真实功放却母线电压抬升、限幅或保护动作。结果看着合理，物理上不成立——这类错误最贵：测试没断言可写，现场却按它做了判断。

三、有功、无功、功率因数

直流里 p = u·i 一目了然；交流里 u 和 i 都是正弦、还可能差一个相位 φ，瞬时功率 p(t) = u(t)·i(t) 随时间波动（含两倍频分量），一个周期平均下来才是真正被消耗 / 转换掉的 有功 P。

把功率拆成两部分：

  • P（有功）：真正转成热、机械功或被送走的平均功率，单位 W
  • Q（无功）：在电源与负载的磁场 / 电场之间来回借还、一个周期净额为零的部分，单位 var
  • S（视在功率） = √(P² + Q²)，单位 VA；cos φ = P / S 即功率因数

类比：来回搬运但不卸货 — Q 像一批货在仓库和车间之间来回运，一个周期下来车间没多收到货，但车（线路电流）和仓库容量（设备容量）实打实被占了。

类比在哪失效：Q 不是「浪费」也不是「损耗」——建立磁场 / 电场必须要它，感性负载没有它转不起来；而且它照样产生电流、压降和发热，设备容量按 S 选，不按 P。仿真里把 u、i 画成同相位，等于把整块无功抹掉了。

对四象限功放的意义：同一个 P，感性负载和容性负载下电流大小、相位、峰值完全不同；装置往回送的也可能是无功为主。只按有功算，波形和电流额定都会算错。

四、仿真里最容易「看着合理却错」的地方

模型通常假设的条件，以及它们在四象限切换处如何露馅：

# 常见假设 真实约束 露馅的工况 结果长什么样
1 理想电压源，内阻 0 输出阻抗 + 闭环带宽 带载突变、回馈瞬间 端电压被拉低 / 抬升，仿真却是平的
2 带宽无限、无延迟 采样 + 计算 + PWM + 滤波都有延迟 陡沿、过零切换、高频 波形边沿过于干净，相位偏小
3 功率 / 电压无上限 额定值、限幅、保护 大功率或冲击 数值超铭牌却无限幅、无告警
4 能量可任意双向吸收 回馈能力取决于前端；否则制动电阻耗散 持续发电 / 回馈 母线电压毫无变化
5 线性、无死区 开关死区、纹波、饱和 小信号、过零附近 过零点平滑无台阶、无畸变
6 采样与输出严格同步 链路延迟、多机不同步 多机并机、闭环 相位对不上，均流算不出来

判据清单

# 看到什么 物理上哪里不成立 该查哪一段
1 装置处于发电 / 回馈工况，母线电压、前端电流毫无变化 能量没被建模，或回馈通道被当成理想吸收 模型假设、前端变流器
2 电压电流瞬时值符号与功率符号对不上（p = u·i） 象限判断错 / 符号约定不一致 采集通道极性、坐标定义
3 感性或容性负载下，u 与 i 波形完全同相位 无功被整块漏掉 负载模型、相位建模
4 输出波形过零切换处平滑连续、无死区无台阶 用了理想源，没有开关 / 死区模型 功放模型
5 输出功率超过设备铭牌额定，结果仍「正常」 边界与保护没建模 额定值、限幅环节

边界提示：这类判据只负责「看出结果不对」，不负责定位是模型错、参数错还是代码错；定位需结合模型、参数与代码逐层排查。

小结

  • 四象限说的是电压电流双向、功率可正可负的能力，不是四种工况名；u-i 平面与 P-Q 平面同名不同物，先确认再说。
  • 功放既能送能量也要能吃回能量，这个接口是仿真最易失真处。
  • 无功不是损耗，但它占电流和设备容量；把 u、i 画成同相位 = 整块漏掉。
  • 象限切换瞬间与持续回馈两段最容易失真，理想源假设是首要嫌疑。
